# Spike S1 on Windows: plot-to-board coordinate mapping

S1 answers one question with data: how do coordinates in a
`kicad-cli pcb export svg` file relate to board coordinates? kdraft
does not assume an answer. The `spike s1` command exports layer SVGs from a
real board, parses them, fits the board-mm to SVG transform, checks it
against every pad, and writes a report.

## What you need

- Windows with Git for Windows and stable Rust (1.92 or newer; `rustup update`).
- KiCad 9.0.x and/or 10.0.x installed (it brings `kicad-cli.exe`).
- The kdraft source tree.

## Run it

In a terminal (PowerShell or Git Bash) in the kdraft folder:

```
cargo run --release -p kdraft-cli -- spike s1 path\to\board.kicad_pcb
```

kdraft finds `kicad-cli.exe` in this order: the `KDRAFT_KICAD_CLI`
environment variable, `PATH`, then `C:\Program Files\KiCad\<version>\bin`
(newest version folder first). The detected path and version are printed
first. To choose a version explicitly:

```
cargo run --release -p kdraft-cli -- spike s1 path\to\board.kicad_pcb --kicad-cli "C:\Program Files\KiCad\9.0\bin\kicad-cli.exe"
cargo run --release -p kdraft-cli -- spike s1 path\to\board.kicad_pcb --kicad-cli "C:\Program Files\KiCad\10.0\bin\kicad-cli.exe"
```

With both versions installed, run it once per version. The output goes to
`s1-out\<board name>-kicad-<version>\` (change the parent folder with
`--out DIR`), so the runs do not overwrite each other.

Suggested boards: one of your own boards, plus
`fixtures\kicad9-minimal.kicad_pcb` from this repository (small, with a
rotated footprint, a back-side part, an oval slot and an arc in the outline).

The run exports the drawing sheet twice: once as the stub board has it, once
with `--drawing-sheet` (kdraft's copy of KiCad's default sheet, or the file
given with `--drawing-sheet path\to\sheet.kicad_wks`, e.g. your company
sheet).

The run takes about 25 kicad-cli calls. Exit code 0 means the verdict is
PASS, 1 FAIL; 2 means kdraft could not run at all (for example kicad-cli not
found; the message says how to point kdraft at it).

## What it does

1. Runs `pcb export svg|drill|pos|stats --help`, `pcb render --help` and
   `sch export bom --help`, and records which flags kdraft uses are
   mentioned.
2. Exports Edge.Cuts, F.Cu, B.Cu, F.Fab and the courtyard (F.Courtyard, falling
   back to F.CrtYd) for each `--page-size-mode` 0, 1 and 2, single layer,
   drawing sheet excluded, black and white; plus one mirrored F.Cu export.
   If an export fails, it retries without each optional flag to find flags the
   installed version rejects.
3. Parses each SVG generically (root size and units, viewBox, nested
   transforms, all path commands) and computes content boxes.
4. Per mode, fits `u = sx*x + ox, v = sy*y + oy` from the Edge.Cuts box,
   refines it on F.Cu pad centres, and reports for F.Cu and B.Cu how many
   pads land within 0.01 mm and 0.05 mm of a plotted shape centre (max and
   RMS residual).
5. Exports a drawing sheet from a stub board (A3, marker texts in the title
   block, one project text variable) with the sheet included, and reports its
   size, the content box against the paper, and which marker texts appear.
6. Runs `pcb export drill` (with report), `pos --format csv` and
   `stats --format json`, and compares hole counts, drill sizes, footprint
   positions and board size with kdraft's own model. Mismatches are reported,
   not fatal.

## What to send back

Zip and send the whole `s1-out` folder. If that is too large, send
`report.md` and `report.json` from each run folder. The overlay files
(`overlay-mode0.svg` etc.) are for a quick visual check: open them in a
browser; red crosses mark where kdraft expects pad centres and the green
rectangle the board outline box. Crosses off their pads mean the fit failed.

## Output folder

| File | Content |
| --- | --- |
| `report.md` | Summary: PASS/FAIL per layer and mode, transforms, verdict line |
| `report.json` | Everything: command lines, exit codes, stderr, SVG analysis, fits, residuals, cross-checks |
| `svg\*.svg` | Raw layer exports |
| `overlay-mode*.svg` | F.Cu plot with expected pad centres and outline box |
| `sheet\` | Stub board, stub project, drawing-sheet SVGs |
| `drill\`, `pos.csv`, `stats.json` | Raw outputs of the other exports |
| `help\*.txt` | `--help` texts |
| `probe\` | Only if an export failed: retries without single flags |
